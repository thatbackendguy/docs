  <section className="caseSection">
    <div className="caseHeader">
      <p className="sectionKicker">Problem</p>
      <h2>Photo folders get messy fast</h2>
      <p className="sectionLead">
        Many personal photo archives contain mixed filenames from phones, cameras, exports, and messaging apps. This tool extracts likely years from filename patterns and organizes files without needing a database or cloud service.
      </p>
    </div>
    <div className="caseGrid">
      <article className="caseCard">
        <h3>Filename parsing</h3>
        <p>Smart regex patterns detect years from common formats such as <code>IMG_20230404_223211.jpg</code>, <code>2020-01-01.png</code>, and burst image names.</p>
      </article>
      <article className="caseCard">
        <h3>Preview first</h3>
        <p>Preview mode simulates the folder organization before files are moved, reducing the risk of unwanted changes.</p>
      </article>
      <article className="caseCard">
        <h3>Offline and portable</h3>
        <p>The compiled binaries run on Windows, macOS, and Linux without external dependencies.</p>
      </article>
