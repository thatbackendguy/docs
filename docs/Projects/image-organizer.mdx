      <p className="sectionKicker">Problem</p>
      <h2>Large media libraries need cautious migration</h2>
      <p className="sectionLead">
        Photo and video collections often live across laptops, external drives, camera dumps, phone exports, screenshots, and chat app folders. Chronify is designed for organizing those collections without loading media contents into memory or forcing risky first-run moves.
      </p>
    </div>
    <div className="caseGrid">
      <article className="caseCard">
        <h3>Recursive scanning</h3>
        <p>Chronify scans nested folders and supports large collections without reading full media contents into memory.</p>
      </article>
      <article className="caseCard">
        <h3>Photo and video support</h3>
        <p>It supports common image, RAW, HEIC/HEIF, and video formats, making it suitable for mixed media libraries.</p>
      </article>
      <article className="caseCard">
        <h3>Manifest-first workflow</h3>
        <p>Every dry-run and apply run can produce a CSV manifest so the migration can be inspected and audited.</p>

  <section className="caseSection">
    <div className="caseHeader">
      <p className="sectionKicker">Date detection</p>
      <h2>Metadata first, filename second</h2>
      <p className="sectionLead">
        Chronify chooses dates in a layered order so trusted media metadata wins when available, while still handling real-world filenames from cameras, phones, screenshots, and WhatsApp exports.
      </p>
    </div>
    <div className="caseGrid">
      <article className="caseCard">
        <h3>1. Native metadata</h3>
        <p>Uses embedded metadata for supported JPEG, TIFF/DNG-style, PNG, and WebP files.</p>
      </article>
      <article className="caseCard">
        <h3>2. Optional tools</h3>
        <p>When <code>-metadata auto</code> is enabled, Chronify can use <code>ffprobe</code>, <code>exiftool</code>, or macOS <code>mdls</code> if present.</p>
      </article>
      <article className="caseCard">
        <h3>3. Fallbacks</h3>
        <p>It then checks filename patterns, filesystem modified time, and finally routes unknown files into <code>_unknown_date/</code>.</p>
      </article>
    </div>
  </section>

  <section className="caseSection">
    <div className="caseHeader">
      <p className="sectionKicker">Workflow</p>
      <h2>Recommended usage</h2>
      <p className="sectionLead">
        The default run is a dry-run. Review the manifest first, then apply the organization with either move or copy mode.
      </p>
    </div>

```bash
go build -o chronify .
```

```bash
./chronify \
  -source "/Volumes/Camera Dump" \
  -dest "/Volumes/Media Library"
```

```bash
./chronify \
  -source "/Volumes/Camera Dump" \
  -dest "/Volumes/Media Library" \
  -apply \
  -mode move
```

```bash
./chronify \
  -source "/Volumes/Camera Dump" \
  -dest "/Volumes/Media Library" \
  -apply \
  -mode copy
```

  <section className="caseSection">
    <div className="caseHeader">
      <p className="sectionKicker">Controls</p>
      <h2>Useful flags</h2>
    </div>
    <div className="caseGrid">
      <article className="caseCard">
        <h3>Input and output</h3>
        <p><code>-source</code> selects the folder to scan recursively.</p>
        <p><code>-dest</code> selects where <code>YYYY/MM</code> folders will be created.</p>
        <p><code>-report</code> sets the CSV manifest path, or <code>none</code>.</p>
      </article>
      <article className="caseCard">
        <h3>Execution mode</h3>
        <p><code>-apply</code> performs changes; omitted means dry-run.</p>
        <p><code>-mode</code> chooses <code>move</code> or <code>copy</code>.</p>
        <p><code>-conflict</code> chooses <code>rename</code> or <code>skip</code> for duplicates.</p>
      </article>
      <article className="caseCard">
        <h3>Date and media filters</h3>
        <p><code>-media</code> selects <code>all</code>, <code>images</code>, or <code>videos</code>.</p>
        <p><code>-metadata</code> selects <code>auto</code>, <code>native</code>, or <code>never</code>.</p>
        <p><code>-min-year</code> and <code>-max-year</code> bound accepted media dates.</p>
      </article>
    </div>
