      <h2>Face recognition often has limited examples per person</h2>
      <p className="sectionLead">
        Traditional classification models need many labeled examples per identity. A Siamese Network learns similarity instead, making it useful for verification tasks where only one or a few reference images are available.
      </p>
    </div>
    <div className="caseGrid">
      <article className="caseCard">
        <h3>Pairwise learning</h3>
        <p>The model learns whether two face images belong to the same identity rather than predicting a fixed class label.</p>
      </article>
      <article className="caseCard">
        <h3>Contrastive signal</h3>
        <p>Positive and negative image pairs help the network learn a distance space where similar faces stay close.</p>
      </article>
      <article className="caseCard">
        <h3>Practical use cases</h3>
        <p>The approach fits access control, personal device unlocking, camera systems, and lightweight identity verification flows.</p>
